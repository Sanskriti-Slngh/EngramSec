# Record and template identity

The earlier whiteboard run grouped 5 concrete canvas paths into one state group and 2 into another. The shapes were similar but a group-level shortest return path could select a different record. Raw observations already retained the concrete URLs, so the raw observations were not lost; the operational grouping and group-level path were unsafe as the only identity available to downstream code.

Graph A keeps existing state groups for compatibility and adds `page_templates` and `record_instances`. A template is a **structural hypothesis**, based on route pattern, session context, safe controls, and form shapes; it does not assert equivalent behavior. An instance reference is keyed by the observed concrete instance-bearing path and context. Observation-backed edges connect instances to their observed groups and templates; action evidence names its source and result instance. The fixture graph is [graph_a.json](agent1/experiments/stateful_fixture_example/graph_a.json). Two SQLite records have a shared template reference but distinct record references.

Exploration keeps separate return-path keys for instances and rejects a restored source with the wrong recognized instance. Existing state groups and raw observations remain intact; no record path is made replay-validated by template membership. In the three final whiteboard runs, two seeded canvases and the one created canvas each had an instance reference. These are observation-backed path references, not proof of complete server-side object identity.

Current inference recognizes UUID/numeric path tokens; opaque slugs, query-identified objects, WebSocket-only identities and identities hidden from the URL are not reliably recognized. Session context uses the configured label and observed marker names, not a proof that two accounts with the same marker names are identical. The grouping audit checks structural shapes, not independent behavioral equivalence. Future work should add explicit, privacy-preserving object/session evidence and independent wrong-instance tests for non-URL identities.

The saved fixture Graph A has 12 instance-to-state/template edges. A separate reference check found that all 12 name existing graph endpoints and an observation listed in a state node. This is a provenance check, not independent proof that every inferred instance or template is semantically correct.
