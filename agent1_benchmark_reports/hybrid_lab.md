breadth. (Used in Stage 0 to show why it is *not* a breadth benchmark.)

## Accuracy
No reference. **16/16 reproduced** (clean). The large **advertised-unexecuted (3410)** reflects the deep
functionality gated behind POST/JS that a read-only run cannot reach — the same class as js_heavy_lab /
stateful_lab, not a breadth problem.

## Verdict

the read-only regime. Correctly characterized in Stage 0 as *not* a breadth benchmark.
